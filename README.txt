NyxFit tanıtım sayfaları (TR / EN / DE) — ekran görüntülü
=========================================================

Dosyalar:
  index.html   → Türkçe
  en.html      → English
  de.html      → Deutsch
  promo.css    → ortak stiller
  img/         → logo + uygulama ekran görüntüleri
    logo.png
    ana, program, programkarti, besin, cinsiyet, vucut, hedef,
    bilgiler, gunsecim, alternatif, salonmodu
    en/  → İngilizce arayüz shot’ları
    de/  → Almanca arayüz shot’ları

Kurulum:
  1. Zip’i aç, tüm içeriği GitHub Pages repo köküne kopyala.
  2. Eski img/ ile karışmasın diye üzerine yazabilirsin (veya yedek al).
  3. Commit + push.

Görseller:
  - logo.png → senin images.zip içindeki logo
  - Diğerleri → Google Play için aldığımız TR/EN/DE telefon ekran görüntüleri
